  <files>ai_debug/static/src/app/app.js</files>
  <action>
Add the following to the AiDebugApp class in app.js:

1. **`get sidebarNodes()` computed getter** — returns a flat array of node descriptors by walking the trace tree depth-first. Called during OWL render so reactive reads are tracked.

   Logic:
   - Filter `this.traces.values()` to get root traces (those with `!t.parent_trace_id`), reverse for newest-first
   - For each root trace, call `this._collectTraceNodes(trace, 0, nodes)`
   - Return the flat `nodes` array

2. **`_collectTraceNodes(trace, depth, nodes)` recursive helper** — emits node descriptors for one trace and its descendants.

   Logic:
   - Push `{ type: 'trace', id: trace.trace_id, depth, trace }` — the trace row itself
   - If `!trace.expanded`, return (TREE-04: collapse hides all descendants)
   - Iterate `trace.iterations.keys()` in REVERSE order (newest first, matching current behavior)
   - For each iteration, push `{ type: 'iter', id: iterId, depth, iter, trace }`
   - If `!iter.expanded`, continue to next iteration (skip tool calls and child traces)
   - For each tool call in the iteration, push `{ type: 'tc', id: tcId, depth, tc, iter, trace }`
   - After each tool call, find child subagent traces: filter `this.traces.values()` where `t.parent_trace_id === trace.trace_id && t.parent_tool_call_id === tc.call_id`
   - For each child trace found, recursively call `this._collectTraceNodes(child, depth + 1, nodes)`

   **CRITICAL:** Iteration rows and tool call rows use the SAME `depth` as their owning trace (flat within trace — TREE-03). Only child subagent traces increment depth (depth + 1).

   **CRITICAL:** Match child traces by `tc.call_id` (the LLM call_id stored on tool call entries), NOT the tool_call_id UUID key. The `parent_tool_call_id` on child traces is the LLM call_id, which corresponds to `tc.call_id`.

3. **`get rootTracesCount()` getter** — returns the count of root traces (traces without parent_trace_id). Used by checkbox logic.

   ```javascript
   get rootTracesCount() {
       let count = 0;
       for (const t of this.traces.values()) {
           if (!t.parent_trace_id) count++;
       }
       return count;
   }
   ```

4. **Fix `get allChecked()` getter** — replace `this.traces.size` with `this.rootTracesCount` so subagent traces don't inflate the denominator:

   ```javascript
   get allChecked() {
       return this.rootTracesCount > 0 && this.state.checkedTraceIds.size === this.rootTracesCount;
   }
   ```

5. **Fix `toggleSelectAll()` method** — only add root trace IDs (not subagent trace IDs) to checkedTraceIds:

   ```javascript
   toggleSelectAll() {
       if (this.allChecked) {
           this.state.checkedTraceIds.clear();
       } else {
           for (const [id, trace] of this.traces) {
               if (!trace.parent_trace_id) {
                   this.state.checkedTraceIds.add(id);
               }
           }
       }
   }
   ```

Place `sidebarNodes` and `_collectTraceNodes` after the existing `selectedIterationId` getter (around line 478). Place `rootTracesCount` near the existing `allChecked` getter.

Do NOT change any bus event handlers, _placeTrace, or detail panel getters.

- Tool call status: show pulse dot while `status === 'running'`, check on success, X on `success === false` (handles the null case when tool_call_completed hasn't arrived yet)

In the `onWillStart` callback (line ~261), after the first-pass loop that loads traces into `this.traces` (lines ~276-278), add a second pass and replace the auto-select logic:

   ```javascript
   // Second pass: validate parent pointers, promote orphans to root
   for (const trace of this.traces.values()) {
       if (trace.parent_trace_id && !this.traces.has(trace.parent_trace_id)) {
           trace.parent_trace_id = null;
           trace.parent_tool_call_id = null;
       }
   }
   ```
   This nulls out parent fields on orphan traces so they render as root traces in the sidebar — consistent with how `sidebarNodes` identifies roots via `!t.parent_trace_id`.

   if (this.state.selectedId === null && this.traces.size > 0) {

           if (!trace.parent_trace_id) {

       }

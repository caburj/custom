- Import `Component, useState` from `@odoo/owl`.
- `JsonTree` extends `Component` with:
  - `static template = "ai_debug.JsonTree"`
  - `static components = { JsonTree }` (self-referential for recursion)
  - `static props` defining: `value` (any JSON value, required), `depth` (Number, optional, default 0), `maxDepth` (Number, optional, default 2), `label` (String, optional — the key name for this node)
  - `setup()`: `this.state = useState({ collapsed: (this.props.depth ?? 0) >= (this.props.maxDepth ?? 2) })`

  - `toggle()` method: flips `this.state.collapsed`
  - `copyToClipboard()` method: `navigator.clipboard.writeText(JSON.stringify(this.props.value, null, 2))`

**json_tree.xml — OWL template:**
- Template name: `ai_debug.JsonTree`
- For scalar values (not object/array): render a `<span>` with CSS class `ai-debug-json-{valueType}` and the stringified value. Null renders as literal `null`.
- For object/array values:
  - A toggle button (caret icon) that calls `toggle()`. When collapsed, show summary: `{...}` or `[...]` with child count like `{5 keys}` or `[3 items]`.
  - When expanded: render each entry as a `<div class="ai-debug-json-entry">` with the key in `<span class="ai-debug-json-key">` followed by a colon, then a recursive `<JsonTree>` for the value with `depth="props.depth + 1"` and `maxDepth="props.maxDepth"`.
- Copy-to-clipboard: a small icon button (fa-clipboard) shown via CSS `:hover` on any object/array node header. Calls `copyToClipboard()`.
- Keep the template compact — recursion depth is bounded by maxDepth default of 2 levels expanded.

**state_diff.js — State diff component with deep recursive diff:**
- Import `Component, useState` from `@odoo/owl`.
- Export a standalone `computeDiff(before, after)` function that returns an array of diff entries:
  ```
  { key: string, status: 'added'|'removed'|'changed'|'unchanged', oldVal: any, newVal: any, children?: DiffEntry[] }
  ```
  Algorithm (from 03-RESEARCH.md Pattern 5):
  - Collect all keys from both objects into a Set.
  - For each key: if only in `after` -> 'added'; if only in `before` -> 'removed'; if both and JSON.stringify equal -> 'unchanged'; if both are non-array plain objects -> 'changed' with recursive `children: computeDiff(a, b)`; otherwise -> 'changed' with oldVal/newVal.
  - Arrays are treated as atomic values (show old vs new, no element-level diff).
- `StateDiff` extends `Component` with:
  - `static template = "ai_debug.StateDiff"`
  - `static props`: `stateBefore` (Object, required), `stateAfter` (Object, required)
  - `setup()`: `this.state = useState({ showUnchanged: false })`
  - Getter `diff`: calls `computeDiff(this.props.stateBefore || {}, this.props.stateAfter || {})`.
  - Getter `changedEntries`: entries where status !== 'unchanged'.
  - Getter `unchangedEntries`: entries where status === 'unchanged'.
  - Getter `unchangedCount`: count of unchanged entries.
  - `toggleUnchanged()` method: flips `this.state.showUnchanged`.

  - 'removed' entries: left column shows value in red background, right column empty/dash.

**debug_panel.js — Main ir.actions.client component:**
- Imports: `Component, onMounted, onPatched, onWillUnmount, useState, useRef` from `@odoo/owl`; `registry` from `@web/core/registry`; `useService` from `@web/core/utils/hooks`; `JsonTree` from `./json_tree/json_tree`; `StateDiff` from `./state_diff/state_diff`.
- `DebugPanel` extends `Component` with:
  - `static template = "ai_debug.DebugPanel"`
  - `static components = { JsonTree, StateDiff }`
  - `static props = ["action", "*"]`

  **setup():**
  - `this.busService = useService("bus_service")`
  - `this.rpc = useService("rpc")`
  - `this.state = useState({ iterations: [], traceStatus: "waiting", traceId: null, connectionStatus: "connecting" })`
  - `this.scrollRef = useRef("timeline")`
  - `this.userScrolledUp = false`
  - Bind event handlers: `this._onIteration = this._onIteration.bind(this)`, `this._onToolCall = this._onToolCall.bind(this)`, `this._onTraceUpdate = this._onTraceUpdate.bind(this)`, `this._onWorkerState = this._onWorkerState.bind(this)`

  **Reading trace_id:** The component reads `trace_id` from the URL query string. Use `this.props.action.context?.trace_id` first; if not present, parse from `window.location.search` (URLSearchParams). Store in `this.state.traceId`.

  **Fetching bus_channel:** On mount, if `trace_id` is available, do an RPC call: `this.rpc('/web/dataset/call_kw', { model: 'ai.debug.trace', method: 'read', args: [[traceId], ['bus_channel', 'state', 'llm_model', 'agent_id', 'iteration_count']], kwargs: {} })`. This returns the bus_channel UUID and trace metadata for the header. Store `this.channel` from the response.

  **onMounted:** After fetching bus_channel via RPC:
  - `this.busService.addChannel(f'ai_debug:trace:{channel}')` — note: the full channel string with prefix.
  - `this.busService.subscribe("ai_debug/iteration", this._onIteration)`
  - `this.busService.subscribe("ai_debug/tool_call", this._onToolCall)`
  - `this.busService.subscribe("ai_debug/trace_update", this._onTraceUpdate)`
  - `this.busService.addEventListener("BUS:WORKER_STATE_UPDATED", this._onWorkerState)`
  - Add scroll event listener on `this.scrollRef.el` to track user scroll position (set `this.userScrolledUp` to true when scrollTop + clientHeight < scrollHeight - 50, false when near bottom).
  - Update `this.state.connectionStatus` from `this.busService.workerState` (map CONNECTED -> "connected", CONNECTING -> "reconnecting", DISCONNECTED -> "disconnected").

  **onPatched:** Auto-scroll: if `!this.userScrolledUp` and `this.scrollRef.el`, set `scrollTop = scrollHeight`.

  **onWillUnmount:**
  - `this.busService.unsubscribe` all three event types.
  - `this.busService.deleteChannel` the channel.
  - `this.busService.removeEventListener("BUS:WORKER_STATE_UPDATED", this._onWorkerState)`
  - Remove scroll event listener.

  **Event handlers:**
  - `_onIteration(payload)`: Push a new iteration object to `this.state.iterations` array: `{ id: payload.iteration_id, index: payload.index, duration_ms: payload.duration_ms, toolCalls: [], expanded: false, detail: null, activeTab: 'messages' }`. Set `traceStatus` to `"running"`.
  - `_onToolCall(payload)`: Find the iteration in `this.state.iterations` by `payload.iteration_id` and push the tool call to its `toolCalls` array: `{ id: payload.tool_call_id, name: payload.tool_name, duration_ms: payload.duration_ms, success: payload.success, expanded: false, detail: null }`.
  - `_onTraceUpdate(payload)`: Update `this.state.traceStatus` from `payload.state`. Update header metadata (iteration_count, etc.).
  - `_onWorkerState()`: Update `this.state.connectionStatus` from `this.busService.workerState`.

  **Expand/collapse with lazy detail fetch:**
  - `toggleIteration(iterationIdx)`: Toggle `iterations[idx].expanded`. If expanding and `detail === null`, do an RPC to fetch full iteration data: `this.rpc('/web/dataset/call_kw', { model: 'ai.debug.iteration', method: 'read', args: [[iteration.id], ['messages_sent', 'raw_response', 'state_before', 'state_after', 'final_message']], kwargs: {} })`. Store result in `iterations[idx].detail`.
  - `toggleToolCall(iterationIdx, toolCallIdx)`: Same pattern — lazy RPC fetch of `ai.debug.tool.call` detail (args, result, state_before, state_after, confirmation_message).
  - `setActiveTab(iterationIdx, tabName)`: Set `iterations[idx].activeTab` to 'messages', 'response', 'state', etc.

  Register: `registry.category("actions").add("ai_debug.debug_panel", DebugPanel)`

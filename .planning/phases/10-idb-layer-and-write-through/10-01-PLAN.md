  <name>Task 1: Create db.js IDB persistence module</name>
  <files>ai_debug/static/src/app/db.js</files>
  <action>
Create `ai_debug/static/src/app/db.js` as a plain ES module (not an OWL service). This module owns all IndexedDB knowledge — app.js should never import from `@web/core/utils/indexed_db` directly.

**Module structure:**

1. **Import and instantiate IndexedDB:**
   ```javascript
   import { IndexedDB } from "@web/core/utils/indexed_db";
   const DB_NAME = "ai_debug_traces";
   const DB_VERSION = 1;
   const STORE = "traces";
   const idb = new IndexedDB(DB_NAME, DB_VERSION);
   ```
   Do NOT use `markRaw` — the instance is a module-level constant, not stored in OWL reactive state.

2. **`probeIDB()` — exported async function:**
   Uses `idb.execute((db) => (db ? "ok" : null))` to probe. Returns `true` if IDB is available, `false` if blocked.

   Key insight: In private browsing, Odoo's `_execute` fires `onerror` which calls `callback(undefined)` and resolves (does NOT reject). The `(db) => (db ? "ok" : null)` guard distinguishes this from success.

3. **`serializeTrace(trace)` — internal function (not exported):**
   Converts the reactive store's trace object to a plain IDB-storable record. Critical details:
   - Include `storedAt: Date.now()` for Phase 11 hydration ordering
   - Convert `trace.iterations` Map to array of `[iterationId, iterationRecord]` entries
   - Convert each iteration's `toolCalls` Map to array of `[toolCallId, toolCallRecord]` entries
   - Preserve Date objects as-is (IDB's structured clone handles them)
   - Do NOT include `expanded` (ephemeral UI state, not persisted)
   - The `trace_id` field is already a UUID hex string from the backend (`uuid.uuid4().hex` in `ai_session.py`) — use it directly as the IDB key

   Fields to include from trace: `trace_id`, `agent_name`, `model_name`, `status`, `started_at`, `ended_at`, `duration_ms`, `instructions`, `tools`, `state_snapshot`, `iterations` (serialized).

   Fields to include from each iteration: `iteration_id`, `trace_id`, `iteration_index`, `has_error`, `receivedAt`, `is_final`, `error`, `messages_sent`, `raw_response`, `toolCalls` (serialized).

   Fields to include from each tool call: `tool_call_id`, `iteration_id`, `tool_name`, `success`, `args`, `result`, `error`, `state_before`, `state_after`, `call_id`.

4. **`writeTrace(trace)` — exported function (NOT async):**
   Calls `serializeTrace(trace)` then returns `idb.write(STORE, trace.trace_id, record)`.
   Returns the Promise so the caller can `.catch()`. Do NOT await internally.

5. **`deleteTrace(traceId)` — exported async function:**
   Calls `idb.delete(STORE, traceId)`. Exposed for Phase 11's delete feature — implement now to avoid modifying db.js later.

Add the `/** @odoo-module **/` pragma at the top of the file (required by Odoo's module system).

Reference: 10-RESEARCH.md "Code Examples > db.js — Complete Module" section for exact patterns. Follow it closely but add the `deleteTrace` export.

1. **Add imports:**

   Add `onWillStart` to the existing OWL import line (alongside `useState`, `reactive`, `onMounted`, etc.).

2. **Add `ephemeralMode` to `this.state` useState:**
   Add `ephemeralMode: false` to the existing `useState({...})` block (alongside `connectionStatus`, `selectedId`, `selectedType`).

3. **Add `onWillStart` hook in `setup()` — place BEFORE the `onMounted` call:**
   ```javascript
   onWillStart(async () => {
       const available = await probeIDB();
       if (!available) {
           console.warn("[ai_debug] IndexedDB unavailable — running in ephemeral mode");
           this.state.ephemeralMode = true;
       }
   });
   ```
   This runs before the component's first render, preventing any flash of "persistence available" state.

4. **Add fire-and-forget write in `_onLoopEnd` handler:**
   After the existing status/ended_at/duration_ms updates (lines ~128-139 in current app.js), add:
   ```javascript
   // Fire-and-forget IDB write — do NOT await
   if (!this.state.ephemeralMode) {
       writeTrace(trace).catch((err) => {
           console.warn("[ai_debug] IDB write failed — switching to ephemeral mode:", err);
           this.state.ephemeralMode = true;
       });
   }
   ```
   The `if (!this.state.ephemeralMode)` guard skips the write entirely when already in ephemeral mode (no point attempting writes that will fail).

   CRITICAL: Do NOT `await writeTrace(...)`. The `_onLoopEnd` handler must remain synchronous with respect to the reactive store update. The `.catch()` handles errors asynchronously.

  <action>
Create a new file `ai_debug/models/ai_provider_patch.py` that monkey-patches `AIApiService._request` to intercept LLM completion responses via `threading.local()`. This is the approved approach from STATE.md — the only way to get token data back to the instrumentation layer without modifying enterprise code.

**Module-level setup:**
- `import threading, time, logging`
- `from odoo.addons.ai.services.ai_api_service import AIApiService`
- `_logger = logging.getLogger(__name__)`
- `_ai_debug_local = threading.local()`
- Save original: `_original_request = AIApiService._request`

**_patched_request(self, method, endpoint, body, **kwargs):**
- Determine if this is a completion endpoint: `is_completion = 'generateContent' in endpoint or endpoint.strip('/').endswith('responses')`
- If NOT a completion endpoint, delegate directly: `return _original_request(self, method, endpoint, body, **kwargs)` — embeddings and transcription calls must not be captured.
- If IS a completion endpoint:
  - Record `t0 = time.monotonic()` before the call
  - Call `result = _original_request(self, method, endpoint, body, **kwargs)`
  - Stash: `_ai_debug_local.last_completion_response = result`
  - Stash: `_ai_debug_local.last_llm_duration_ms = int((time.monotonic() - t0) * 1000)`
  - Return `result`
- The entire function body should be wrapped in try/except: on ANY exception during stashing, log warning and still return the result normally. Instrumentation must never break the LLM call.

**Apply the patch at module level:**
- `AIApiService._request = _patched_request`

**_extract_tokens_openai(raw_response):**
- Extract from `raw_response.get('usage')`. If no `usage` key, return `None`.
- Build canonical dict: `{'input': usage.get('input_tokens', 0), 'output': usage.get('output_tokens', 0), 'total': usage.get('total_tokens', 0)}`
- `total` uses the raw provider value (per CONTEXT.md locked decision), NOT computed from input + output. If missing, defaults to 0 per TOKN-04.
- Sparse fields: `if cached := usage.get('input_tokens_details', {}).get('cached_tokens', 0): tokens['cached'] = cached`
- Sparse fields: `if reasoning := usage.get('output_tokens_details', {}).get('reasoning_tokens', 0): tokens['reasoning'] = reasoning`
- Wrap in try/except: on failure, `_logger.warning("ai_debug: failed to extract OpenAI token data", exc_info=True)` and return `None`.

**_extract_tokens_google(raw_response):**
- Extract from `raw_response.get('usageMetadata')`. If no `usageMetadata` key, return `None`.
- Build canonical dict: `{'input': usage.get('promptTokenCount', 0), 'output': usage.get('candidatesTokenCount', 0), 'total': usage.get('totalTokenCount', 0)}`
- Sparse fields: `if cached := usage.get('cachedContentTokenCount', 0): tokens['cached'] = cached`
- Sparse fields: `if reasoning := usage.get('thoughtsTokenCount', 0): tokens['reasoning'] = reasoning`
- Wrap in try/except: on failure, `_logger.warning("ai_debug: failed to extract Google token data", exc_info=True)` and return `None`.

**pop_last_completion_data():**
- Public function called by ai_session.py after each iteration.
- Read `raw_response = getattr(_ai_debug_local, 'last_completion_response', None)`
- Read `llm_duration_ms = getattr(_ai_debug_local, 'last_llm_duration_ms', None)`
- **Immediately clear** both: `_ai_debug_local.last_completion_response = None` and `_ai_debug_local.last_llm_duration_ms = None` — prevents cross-iteration contamination (Pitfall 1 from research).
- If `raw_response` is None, return `{'tokens': None, 'llm_duration_ms': llm_duration_ms}` (duration may still be captured on errors).
- Detect provider: try OpenAI first (`raw_response.get('usage')`), then Google (`raw_response.get('usageMetadata')`).
- Call the appropriate extractor. Return `{'tokens': extracted_tokens, 'llm_duration_ms': llm_duration_ms}`.
- Wrap in try/except: on failure, log warning, return `{'tokens': None, 'llm_duration_ms': None}`.

**Update `ai_debug/models/__init__.py`:**
- Add `from . import ai_provider_patch` as the FIRST import line (before ir_websocket, ai_session, ai_agent) so the patch runs before any provider service is instantiated.

**Critical anti-patterns to avoid:**
- Do NOT store tokens in `_debug_ctx` — that dict is shared across iterations; token data is per-iteration from the thread-local.
- Do NOT filter endpoints too broadly — only `/responses` (OpenAI) and `:generateContent` (Google). NOT `/embeddings`, `/audio/transcriptions`, `:embedContent`, `:batchEmbedContents`.
- Do NOT compute total from input + output — CONTEXT.md says use the raw provider value.

**In `_run_agentic_loop`, after the iteration event block (the `if 'tool_calls' in item or 'final_message' in item:` branch):**

After the `iteration_id` assignment and `messages_snapshot` capture, BEFORE emitting the iteration bus event:

1. Call `completion_data = pop_last_completion_data()` — retrieves tokens + LLM duration from thread-local and clears it.

2. Extract tokens: `tokens = completion_data.get('tokens')`. Per TOKN-04 and CONTEXT.md locked decision ("On errored iterations: skip the tokens field entirely — absence signals failure"), include the `tokens` key in the event dict ONLY if `tokens is not None`. When present, `tokens` is already the canonical `{input, output, total}` dict with optional `cached`/`reasoning`.

3. Extract LLM duration: `llm_duration_ms = completion_data.get('llm_duration_ms')`. Include as `duration_ms` in the iteration event (per TIME-01). If None (unlikely but defensive), omit the field.

4. Determine provider name: The provider name can be inferred from the token data structure (OpenAI has 'usage', Google has 'usageMetadata') — but this is already determined inside the extractor. Instead, add provider detection in `pop_last_completion_data` or determine it here. Simplest: check the raw response stashed data. BUT the raw response is already cleared by pop. Better approach: pass `model` to `_ai_debug_resolve_provider_name(model)` using the existing `AIProvider.get_by_model` call. Add a helper:
   ```python
   def _ai_debug_resolve_provider_name(self, model):
       try:
           from odoo.addons.ai.services.ai_provider import AIProvider
           provider = AIProvider.get_by_model(self.env, model)
           return provider.name  # "openai" or "google"
       except Exception:
           return None
   ```
   Call it once before the loop starts: `provider_name = self._ai_debug_resolve_provider_name(model)` and include in every iteration event as `'provider': provider_name`.

5. Update the iteration bus event dict to include the new fields:
   ```python
   iteration_payload = {
       'type': 'iteration',
       'trace_id': trace_id,
       'iteration_id': iteration_id,
       'iteration_index': iteration_count,
       'messages_sent': messages_snapshot,
       'raw_response': item.get('metadata'),
       'has_tool_calls': 'tool_calls' in item,
       'is_final': 'final_message' in item,
       'provider': provider_name,
   }
   if tokens is not None:
       iteration_payload['tokens'] = tokens
   if llm_duration_ms is not None:
       iteration_payload['duration_ms'] = llm_duration_ms
   self._ai_debug_bus_send('iteration', iteration_payload)
   ```

6. For ERROR iteration events (both UserError and Exception handlers): do NOT add tokens (per CONTEXT.md: "On errored iterations: skip the tokens field entirely"). DO capture duration if available — call `pop_last_completion_data()` and include `duration_ms` if present. Include `provider` as well.

**In `_handle_tool_calls`, add per-tool-call timing:**

After the `_tc_id_map` dict is built and the tool_call_started events are emitted, but BEFORE the `for item in super()._handle_tool_calls(...)` loop:

1. Record batch start time: `_tc_start_times = {tc['call_id']: time.monotonic() for tc in tool_calls}` — captures the moment just before tool execution begins. This slightly overestimates individual tool duration for batch execution but is accurate enough per CONTEXT.md ("aggregate tool execution duration" is the requirement at iteration level).

2. In the `tool_call_completed` event dict, add:
   ```python
   'duration_ms': int((time.monotonic() - _tc_start_times.get(call_id, time.monotonic())) * 1000),
   ```
   Place this alongside the existing fields (tool_name, result, success, error).

3. For confirmation events (the `tool_confirmation_request` branch), also add `duration_ms` with the same pattern.

**What was built:** Complete SCSS migration from hardcoded Catppuccin colors to Odoo SCSS variables (Plan 01) plus dark-only syntax highlighting file with manifest integration and Bootstrap error banners (Plan 02).

**How to verify:**

**Preparation:**
1. Restart the Odoo server to recompile CSS bundles (the SCSS changes require fresh asset compilation)
2. Clear browser cache or use hard refresh (Ctrl+Shift+R)

**Test 1: Light Mode**
1. Set `color_scheme=light` cookie (or use Odoo Preferences to set light theme)
2. Navigate to `/ai-debug`
3. Verify:
   - Background is light (consistent with Odoo standard light UI) — sidebar, header, and main area all use the same light background
   - Borders define panel separation (no background depth differences)
   - Text is dark on light background (readable)
   - If a trace is visible: selected row has a light teal background tint (no left blue border)
   - JSON syntax colors are readable on light background
   - Notebook tabs look like standard Odoo tabs (no custom dark styling)
4. Open DevTools Network tab: confirm NO request for `ai_debug.assets_dark` CSS

**Test 2: Dark Mode**
1. Set `color_scheme=dark` cookie (or use Odoo Preferences to set dark theme)
2. Hard refresh `/ai-debug`
3. Verify:
   - Background is dark (consistent with Odoo dark palette)
   - JSON syntax highlighting uses distinct colors (teal keys, green strings, amber numbers, mauve booleans)
   - Status dots are green (connected) or red (disconnected)
   - If a trace has errors: error banner renders as a Bootstrap alert-danger (red-tinted background, not custom rgba styling)
   - Dialog (click a truncated text to open TextPopupDialog): renders with dark background, NO inverted close button
   - Notebook tabs render naturally (enterprise dark styling, no custom overrides)
4. Open DevTools Network tab: confirm request for `ai_debug.assets_dark` CSS bundle

**Test 3: StateDiff Tints (if trace data available)**
1. Select a tool call with state changes
2. Verify diff tints: added rows have subtle green tint, removed rows have subtle red tint, changed rows have subtle yellow tint
3. Tints should be visible but not overpowering in both light and dark modes

**Test 4: Asset Compilation**
1. Check browser console for any SCSS compilation errors
2. Verify no 404s for CSS bundles in Network tab

**Resume signal:** Type "approved" if all checks pass, or describe specific visual issues that need fixing.

**1. `loop_detail.js` — LoopDetail component:**

```javascript
static template = "ai_debug.LoopDetail";
static components = { Notebook, CopyButton, JsonTree };
static props = {
    trace: Object,
};
```

- `setup()`: Initialize `this.dialog = useService("dialog");`
- `openTextPopup(title, content, language)`: `this.dialog.add(TextPopupDialog, { title, content, language: language || "markdown" });`
- `get ragContextMessages()`: Extract RAG context from the first iteration's `messages_sent`. Logic:
  ```javascript
  const firstIter = [...this.props.trace.iterations.values()][0];
  if (!firstIter || !firstIter.messages_sent) return null;
  return firstIter.messages_sent.filter(
      m => m.role === "system" && m.content !== this.props.trace.instructions
  );
  ```
  Returns null if no first iteration yet, or an array of filtered system messages.
- `get instructionsContent()`: Returns `this.props.trace.instructions || ""` — for the copy button function.
- `get toolsJson()`: Returns `JSON.stringify(this.props.trace.tools, null, 2)` — for copy button.

**`loop_detail.xml` template structure:**
```xml
<div class="ai-detail-view">
    <!-- Header -->
    <div class="ai-detail-header">
        <span class="ai-detail-type-badge">Loop</span>
        <span class="ai-detail-name" t-esc="props.trace.agent_name"/>
        <span class="ai-detail-meta" t-esc="props.trace.model_name"/>
    </div>

    <!-- Tabbed content -->
    <Notebook>
        <t t-set-slot="system_prompt" title="'System Prompt'" isVisible="true">
            <div class="ai-detail-section">
                <div class="ai-detail-section-header">
                    <span>System Prompt</span>
                    <CopyButton content="() => this.instructionsContent"/>
                </div>
                <!-- Truncated text preview; click opens popup -->
                <div class="ai-detail-text-preview"
                     t-on-click="() => this.openTextPopup('System Prompt', props.trace.instructions, 'markdown')"
                     t-esc="props.trace.instructions"/>
            </div>
        </t>

        <t t-set-slot="rag_context" title="'RAG Context'" isVisible="true">
            <div class="ai-detail-section">
                <div class="ai-detail-section-header">
                    <span>RAG Context</span>
                </div>
                <div t-if="!ragContextMessages" class="ai-detail-empty-tab">
                    Waiting for first iteration to capture RAG context...
                </div>
                <div t-elif="ragContextMessages.length === 0" class="ai-detail-empty-tab">
                    No RAG context detected in this trace.
                </div>
                <t t-else="">
                    <t t-foreach="ragContextMessages" t-as="msg" t-key="msg_index">
                        <div class="ai-detail-section">
                            <div class="ai-detail-section-header">
                                <span t-esc="'System Message ' + (msg_index + 1)"/>
                                <CopyButton content="() => msg.content"/>
                            </div>
                            <div class="ai-detail-text-preview"
                                 t-on-click="() => this.openTextPopup('RAG Context', msg.content, 'markdown')"
                                 t-esc="msg.content"/>
                        </div>
                    </t>
                </t>
            </div>
        </t>

        <t t-set-slot="tools" title="'Tools Definition'" isVisible="true">
            <div class="ai-detail-section">
                <div class="ai-detail-section-header">
                    <span>Tools Definition</span>
                    <CopyButton content="() => this.toolsJson"/>
                </div>
                <JsonTree data="props.trace.tools" onExpandText="(title, content) => this.openTextPopup(title, content, 'json')"/>
            </div>
        </t>
    </Notebook>
</div>
```

NOTE: `CopyButton`'s `content` prop expects a **function** returning a string, NOT a string directly. Use arrow function syntax: `content="() => this.instructionsContent"`.

**2. `iter_detail.js` — IterationDetail component:**

```javascript
static template = "ai_debug.IterationDetail";
static components = { Notebook, CopyButton, JsonTree, StateDiff };
static props = {
    iteration: Object,
};
```

Import `StateDiff` from `./state_diff`.

- `setup()`: Initialize `this.dialog = useService("dialog");`
- `openTextPopup(title, content, language)`: Same as LoopDetail.
- `get messagesJson()`: `JSON.stringify(this.props.iteration.messages_sent, null, 2)`
- `get responseJson()`: `JSON.stringify(this.props.iteration.raw_response, null, 2)`
- `get stateBefore()`: State diff comes from tool calls in this iteration, NOT from the iteration payload itself. Collect `state_before` from the first tool call and `state_after` from the last tool call. Logic:
  ```javascript
  const toolCalls = [...this.props.iteration.toolCalls.values()];
  if (toolCalls.length === 0) return null;
  return toolCalls[0].state_before;
  ```
- `get stateAfter()`:
  ```javascript
  const toolCalls = [...this.props.iteration.toolCalls.values()];
  if (toolCalls.length === 0) return null;
  return toolCalls[toolCalls.length - 1].state_after;
  ```

NOTE: Per research and Phase 5 decisions, state snapshots are batch-level and live on tool_call payloads, NOT on iteration payloads. The iteration's "State Diff" tab aggregates from its child tool calls.

**5. Add getter properties on the class (after `statusLabel` getter):**

```javascript
get allChecked() {
    return this.traces.size > 0 && this.state.checkedTraceIds.size === this.traces.size;
}

get someChecked() {
    return this.state.checkedTraceIds.size > 0 && !this.allChecked;
```

**6. Add toggle and delete methods (after the existing `clearAll()` method or in its place):**

```javascript
toggleTraceCheck(traceId) {
    if (this.state.checkedTraceIds.has(traceId)) {
        this.state.checkedTraceIds.delete(traceId);
    } else {
        this.state.checkedTraceIds.add(traceId);
    }
}

toggleSelectAll() {
    if (this.allChecked) {
        this.state.checkedTraceIds.clear();
    } else {
        for (const id of this.traces.keys()) {
            this.state.checkedTraceIds.add(id);
        }
    }
}

deleteCheckedTraces() {
    const ids = [...this.state.checkedTraceIds];
    if (ids.length === 0) return;
    // Clear checkbox selection first
    this.state.checkedTraceIds.clear();
    // Clear detail panel selection if the viewed trace is being deleted
    if (ids.includes(this.state.selectedId)) {
        this.state.selectedId = null;
        this.state.selectedType = null;
    }
    // Remove from reactive Map (triggers OWL re-render immediately)
    for (const id of ids) {
        this.traces.delete(id);
    }
    // Delete from IDB (fire-and-forget per item — deleteTrace already exported from db.js)
    for (const id of ids) {
        deleteTrace(id).catch((err) => {
            console.warn("[ai_debug] IDB delete failed for", id, err);
        });
    }
}
```

**7. Remove the old `clearAll()` method:**

**1. Replace the sidebar header (`.ai-tree-header` div) with the new action bar layout:**

Replace the existing header:
```xml
<div class="ai-tree-header">
```

With the new select-all + action bar:
```xml
<div class="ai-tree-header">
    <div class="ai-tree-header-left">
        <input type="checkbox"
               class="ai-tree-select-all"
               t-ref="selectAll"
               t-att-checked="allChecked"
               t-on-change.stop="toggleSelectAll"/>
        <span>Traces</span>
    </div>
    <div class="ai-tree-header-actions">
        <button class="ai-tree-action-btn"
                t-att-disabled="state.checkedTraceIds.size === 0 or undefined"
                t-on-click="deleteCheckedTraces"
                title="Delete selected">&#x1F5D1;</button>
    </div>
</div>
```

Notes:
- `t-att-disabled="expr or undefined"` — the `or undefined` idiom removes the `disabled` attribute entirely when the expression is false, avoiding `disabled="false"` which still disables in some browsers
- `t-on-change.stop` on the selectAll checkbox prevents the event from bubbling
- `t-ref="selectAll"` connects to the `useRef("selectAll")` for indeterminate state sync
- The `ai-tree-header-actions` div is designed to accommodate a future Export button (Phase 12)
- If `state.checkedTraceIds.size` does not work reactively in the template (OWL Set reactivity open question), replace with a getter that returns the size, e.g., `get checkedCount() { return this.state.checkedTraceIds.size; }` and use `checkedCount === 0 or undefined` in the template

The `.stop` modifier is critical — without it, the checkbox click event would bubble up to any ancestor click handler and potentially change the detail panel selection (Pitfall 6 from research). The existing `toggleExpand` chevron already uses `.stop` — same pattern.

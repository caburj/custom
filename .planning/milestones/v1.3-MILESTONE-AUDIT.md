## Tech Debt

### Phase 11: Hydration and Trace Management
- **Minor UX edge case:** If the selected item is a child (iteration/tool call) of a deleted trace, the detail panel shows the fallback "Select a trace..." state rather than proactively clearing selection. No crash occurs — all getters guard with `return null` and the template has a `t-else` fallback.

### Phase 12: Export and Import
- **Degraded standalone mode:** If dialog service is unavailable in a non-standard standalone context, import error dialogs are silently suppressed. The `try/catch` around `useService("dialog")` sets `this.dialog = null`, and all dialog call sites check `if (this.dialog)`. Normal Odoo production path (with MainComponentsContainer registered) is fully wired.

### Total: 2 items across 2 phases (neither is a blocker)

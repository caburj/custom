## E2E Flows (2/2 complete)

### Dark Mode Flow
1. User sets `color_scheme=dark` cookie
2. Controller reads via `webclient_rendering_context()` → `{'color_scheme': 'dark', ...}`
3. Template `t-if="color_scheme == 'dark'"` → true → loads `ai_debug.assets_dark`
4. Dark bundle compiles: `ai_debug.assets` + `web.dark_mode_variables` + `*.dark.scss`
5. App renders with Odoo dark palette, amber JSON numbers, Bootstrap dark alerts

### Light Mode Flow
1. User has `color_scheme=light` or no cookie
2. Controller returns `{'color_scheme': 'light', ...}`
3. Template falls to `t-else` → loads `ai_debug.assets`
4. Light bundle compiles: all SCSS except `*.dark.scss` (removed by manifest directive)
5. App renders with Odoo light palette, gray JSON numbers

**No broken flows.** Both paths are fully connected from cookie → controller → template → bundle → SCSS → rendered output.

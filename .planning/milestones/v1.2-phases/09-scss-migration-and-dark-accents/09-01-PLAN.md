**1. Notebook tab override block (COMP-01)**

Enterprise's `notebook.dark.scss` handles dark mode natively via CSS variables. The `flex: 1; display: flex; flex-direction: column;` layout on `.o_notebook` and `flex: 1; overflow-y: auto;` on `.o_notebook_content` are needed for the detail view layout — move these to a simpler rule:

```scss
// Notebook layout (flex fill for detail view)
.ai-debug-detail .o_notebook {
    flex: 1;
    display: flex;
    flex-direction: column;

    .o_notebook_content {
        flex: 1;
        overflow-y: auto;
    }
}
```

This keeps ONLY the layout properties. All color/border/background overrides are deleted.

**2. Dialog override block (COMP-02)**

  <name>Task 1: Implement reactive trace store, bus handlers, and selection methods in app.js</name>
  <files>ai_debug/static/src/app/app.js</files>
  <action>
Rewrite `app.js` to add the reactive trace store and selection state while preserving the existing bus connection infrastructure.

**Imports:** Add `reactive`, `onPatched`, `useRef` to the OWL import. Keep `Component`, `useState`, `onMounted`, `onWillUnmount`. Keep `useService` from `@web/core/utils/hooks`.

**Trace store (in setup):**
- `this.traces = reactive(new Map())` — NOT inside useState. This is the top-level reactive Map.
- Each trace entry created by `_onNewTrace` contains: `{ trace_id, agent_name, model_name, status: 'running', started_at: new Date(), ended_at: null, duration_ms: null, expanded: true, iterations: reactive(new Map()) }`
- Each iteration entry created by `_onIteration` contains: `{ iteration_id, trace_id, iteration_index, has_error: !!payload.error, receivedAt: new Date(), expanded: false, toolCalls: reactive(new Map()) }`
- Each tool call entry created by `_onToolCall` contains: `{ tool_call_id, iteration_id, tool_name, success: payload.success }`

**Selection state (in setup):**
- Extend existing `this.state = useState({...})` to include `selectedId: null, selectedType: null` alongside existing `connectionStatus`.

**Bus event handlers** — replace the single `_onBusNotification` console.log handler with four separate handlers:

`_onNewTrace(payload)`: Create trace entry in `this.traces.set(payload.trace_id, {...})`. The `iterations` sub-Map must be `reactive(new Map())`. Set `expanded: true` (locked decision: new loops start expanded). NEVER touch `this.state.selectedId`.

`_onIteration(payload)`: Look up trace via `this.traces.get(payload.trace_id)`. If not found, return silently. Create iteration entry via `trace.iterations.set(payload.iteration_id, {...})`. The `toolCalls` sub-Map must be `reactive(new Map())`. Only create if not already present (`!trace.iterations.has(payload.iteration_id)`). NEVER touch `this.state.selectedId`.

`_onToolCall(payload)`: Look up trace via `payload.trace_id`, then iteration via `payload.iteration_id`. If either not found, return silently. Create tool call entry via `iteration.toolCalls.set(payload.tool_call_id, {...})`. NEVER touch `this.state.selectedId`.

`_onLoopEnd(payload)`: Look up trace. Update `trace.status` based on `payload.termination_reason`: `'success'` for success, `'max_iterations'` for max_iterations, `'error'` for anything else. Set `trace.ended_at = new Date()` and `trace.duration_ms = payload.duration_ms`. NEVER touch `this.state.selectedId`.

**Bus subscription wiring:** Update the `onMounted` block to subscribe each of the four types to its specific handler:
```javascript
this.busService.subscribe("new_trace", this._onNewTrace);
this.busService.subscribe("iteration", this._onIteration);
this.busService.subscribe("tool_call", this._onToolCall);
this.busService.subscribe("loop_end", this._onLoopEnd);
```
Update `onWillUnmount` to unsubscribe each of the four handlers correspondingly.
Remove `this._onBusNotification` and the old loop-based subscribe/unsubscribe pattern. Keep `_subscribedTypes` if useful for the unsubscribe loop, or inline the four calls.

**Selection methods:**
- `selectItem(id, type)`: Set `this.state.selectedId = id` and `this.state.selectedType = type`. If `type === 'trace'`, also set `this.traces.get(id).expanded = true` (locked decision: clicking loop selects AND expands).
- `toggleExpand(id, type)`: If `type === 'trace'`, toggle `this.traces.get(id).expanded`. For iterations, accept `(traceId, iterationId)` — toggle `this.traces.get(traceId).iterations.get(iterationId).expanded`.
- `clearAll()`: Call `this.traces.clear()` (reactive Map.clear() notifies all observers). Set `this.state.selectedId = null` and `this.state.selectedType = null`.

**Ancestor getters** (computed properties used in template for breadcrumb tinting):
- `get selectedTraceId()`: If selectedType is 'trace', return selectedId. If 'iteration', iterate traces to find which one owns the iteration. If 'tool_call', iterate traces then iterations to find which one owns the tool call. Return null if none found.
- `get selectedIterationId()`: If selectedType is 'iteration', return selectedId. If 'tool_call', iterate to find parent iteration. Return null otherwise.

**Keep existing:** `statusColor` and `statusLabel` getters, `_onWorkerState` handler, all bus connection lifecycle code.

**Level 0 — Loop entries:**
```xml
<t t-foreach="[...traces.keys()]" t-as="traceId" t-key="traceId">
    <t t-set="trace" t-value="traces.get(traceId)"/>
    <div class="ai-tree-row level-0"
         t-att-class="{
             'selected': state.selectedId === traceId,
             'ancestor': selectedTraceId === traceId and state.selectedId !== traceId
         }"
         t-att-data-node-id="traceId">
        <span class="ai-tree-chevron"
              t-att-class="{'expanded': trace.expanded}"
              t-on-click.stop="() => this.toggleExpand(traceId, 'trace')">&#x203A;</span>
        <span class="ai-tree-label"
              t-on-click="() => this.selectItem(traceId, 'trace')">
            <t t-esc="trace.agent_name or 'Unknown Agent'"/>
            <span class="ai-tree-label-dim"> · <t t-esc="trace.model_name or ''"/></span>
        </span>
        <!-- Status indicator -->
        <span t-if="trace.status === 'running'" class="ai-debug-pulse-dot small"/>
        <span t-elif="trace.status === 'success'" class="ai-tree-status success">&#x2713;</span>
        <span t-elif="trace.status === 'error'" class="ai-tree-status error">&#x2717;</span>
        <span t-elif="trace.status === 'max_iterations'" class="ai-tree-status warn">&#x23F8;</span>
    </div>
    ...iterations when expanded...
</t>
```

Note: Use `&#x203A;` for the chevron (right single angle quote `›`). Use `&#x2713;` for checkmark, `&#x2717;` for X, `&#x23F8;` for pause.

**Level 1 — Iteration entries (inside loop entry, when trace.expanded):**
```xml
<t t-if="trace.expanded">
    <t t-foreach="[...trace.iterations.keys()].reverse()" t-as="iterationId" t-key="iterationId">
        <t t-set="iteration" t-value="trace.iterations.get(iterationId)"/>
        <div class="ai-tree-row level-1"
             t-att-class="{
                 'selected': state.selectedId === iterationId,
                 'ancestor': selectedIterationId === iterationId and state.selectedId !== iterationId
             }"
             t-att-data-node-id="iterationId">
            <span class="ai-tree-chevron"
                  t-att-class="{'expanded': iteration.expanded}"
                  t-on-click.stop="() => this.toggleExpand(traceId, iterationId)">&#x203A;</span>
            <span class="ai-tree-label"
                  t-on-click="() => this.selectItem(iterationId, 'iteration')">
                Iteration <t t-esc="iteration.iteration_index"/>
                <t t-if="iteration.has_error"><span class="ai-tree-label-error"> · error</span></t>
            </span>
        </div>
        ...tool calls when expanded...
    </t>
</t>
```

IMPORTANT: Iterations in REVERSE order (`[...trace.iterations.keys()].reverse()`) per SIDE-02 locked decision (latest on top).

IMPORTANT: `toggleExpand` for iterations takes `(traceId, iterationId)` as separate args — the JS method needs both to navigate the nested Map. Adjust the JS `toggleExpand` method signature to handle this: when called with two string args, treat first as traceId and second as iterationId.

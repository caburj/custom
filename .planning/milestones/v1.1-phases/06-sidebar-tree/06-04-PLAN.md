  <action>
In `ai_debug/static/src/app/app.scss`, change the `.ai-tree-content` rule block (currently lines 80-85) from:

```scss
.ai-tree-content {
    flex: 1;
    overflow-y: auto;
    display: flex;
    flex-direction: column;
}
```

to:

```scss
.ai-tree-content {
    flex: 1;
    overflow-y: auto;
    min-height: 0;
}
```

Explanation of each change:
- `flex: 1` stays — it fills remaining space below the pinned `.ai-tree-header` inside the flex-column `.ai-debug-sidebar`.
- `overflow-y: auto` stays — it enables the scrollbar when content exceeds allocated height.
- `min-height: 0` added — overrides the default `min-height: auto` on flex items, allowing the element to shrink below its content size so overflow actually triggers.
- `display: flex; flex-direction: column` REMOVED — this was causing the container to grow to fit all children (flex column expands intrinsically) rather than clipping at its bounded height. Plain block layout is correct for a list of `.ai-tree-row` divs.

Also verify that `.ai-debug-sidebar-empty` still works: it uses `display:flex;flex:1;align-items:center;justify-content:center` to center the empty-state content. Since `.ai-tree-content` is no longer a flex parent, `.ai-debug-sidebar-empty` must be self-centering. Check the current rule — it already has its own `display:flex` and `flex:1`, so it will stretch to fill the block container and center its children internally. No change needed.

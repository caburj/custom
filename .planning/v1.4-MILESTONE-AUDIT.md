## Cross-Phase Integration

### Wired Connections (8/8 verified)

1. **Python → JS bus events:** new_trace payload fields consumed by _onNewTrace ✓
2. **tool_call_started/completed split:** Emitted by ai_session.py, consumed by app.js handlers ✓
3. **Context threading chain:** _handle_tool_calls → ai.agent override → child session reads context ✓
4. **Pending-child buffer:** _pendingChildren keyed by parent_tool_call_id, flushed by _onToolCallStarted ✓
5. **Trace parent fields → sidebarNodes:** parent_trace_id/parent_tool_call_id consumed by _collectTraceNodes ✓
6. **serializeTrace → hydrateTrace:** Parent fields written to IDB, restored via ...plain spread ✓
7. **sidebarNodes → template:** Getter consumed by single t-foreach in app.xml ✓
8. **rootTracesCount → checkbox logic:** allChecked and toggleSelectAll use rootTracesCount ✓

### Integration Gaps

1. **DATA-02 (export cascade):** `exportSelected()` serializes only checked root traces. Subagent traces have no checkbox and are silently excluded. `_collectDescendantIds` helper exists but isn't called by export.
2. **DATA-03 (orphan validation):** `onWillStart` single-pass hydration. No second pass to validate parent pointers. Orphan child traces with stale `parent_trace_id` are silently invisible.
